# Cellaria

**Вычислительная модель на принципе локальной редукции.**

Состояние двумерной решётки изменяется только замещением локально-связанной
группы ячеек по фиксированному правилу. Нет процессора, нет шины, нет общей памяти.
Правила — это данные. Жадный арбитраж с приоритетом и возрастом.
Цепочечный сдвиг — единственный способ перемещения данных.
Граничный ввод-вывод через каналы.

## Что это

Cellaria — это не клеточный автомат. Конфиг описывает правила и границу,
но не наполняет решётку данными. Ввод данных — через API (`push_input`)
или кнопку «Push Input» в GUI. Вывод — через output-каналы.

Подробнее: [Спецификация](specs/specification.md)

```bash
cargo build
cargo build --release  # оптимизированная сборка
```

## Запуск

```bash
# Запуск с конфигом по умолчанию (configs/collision.yaml), 10 тиков
cargo run

# Явное указание конфига
cargo run -- configs/cascade.yaml

# Указание конфига и количества тиков
cargo run -- configs/overflow.yaml --ticks 20
```

## Тестирование

```bash
cargo test
```

## Конфигурация

Примеры YAML-конфигов находятся в директории `configs/`:

| Файл | Описание |
|------|----------|
| `cascade.yaml` | Каскадное применение правил — цепочка превращений |
| `collision.yaml` | Конфликт правил на одной ячейке — демонстрация арбитража |
| `conflict.yaml` | Более сложный конфликт с перекрытием областей |
| `io.yaml` | Ввод-вывод через граничные каналы (требует `push_input` для подачи данных)  |
| `overflow.yaml` | Цепочечный сдвиг с различными действиями overflow |
| `parallel.yaml` | Параллельные неконфликтующие правила |
| `priority.yaml` | Приоритеты правил |
| `turing.yaml` | Машина Тьюринга — доказательство тьюринг-полноты |

## Архитектура

- `types` — базовые типы (ячейка, правило, сдвиг, канал)
- `storage` — абстракция хранилища решётки (VecStorage, ChunkStorage)
- `grid` — обёртка Grid над хранилищем
- `engine` — пять фаз тика симуляции (input, detect, arbitrate, apply, flush)
- `config` — загрузка правил из YAML
- `rule_store` — самомодификация правил через канальный протокол
