# Changelog

## [Unreleased]

Сравнение с последней версией на GitHub (`v0.3.0: 2D patterns`, `d0af206`).

### Fixed

Баги, найденные ревью кода и property-based фаззингом (`proptest`), с regression-тестами:

- `Cell.age` переименован в `born_at`: возраст теперь вычисляется как
  `generation - born_at` (глобальный счётчик поколений в `Grid`), а не хранится
  и не продвигается на каждой ячейке — заодно делает `advance_age` операцией
  O(1) вместо обхода всех ячеек.
- `RuleMatch` получил поле `rule_idx` — несколько правил могут иметь одинаковый
  `id` (недетерминированный выбор), и без `rule_idx` арбитраж/применение могли
  резолвиться не к тому правилу, которое реально сработало.
- Тай-брейк в `arbitrate()` сделан полностью явным:
  `priority → age → rule_id → x → y → rule_idx` (раньше при равенстве
  priority+age порядок был implementation-defined) — гарантирует идентичный
  результат между глобальным последовательным и локальным раундовым
  арбитражем.
- `ConflictGraph::build` теперь проверяет правило на конфликт с самим собой
  (`rule_self_conflicts`) — раньше правило, конфликтующее само с собой в двух
  перекрывающихся позициях, не обнаруживалось, что нарушало теорему
  «бесконфликтность ⇒ арбитраж не нужен».
- `arbitrate()` больше не отбрасывает affected cells с отрицательными
  координатами из проверки конфликтов (раньше guard `>= 0` пропускал такие
  ячейки мимо `used_cells`, позволяя двум пересекающимся в отрицательных
  координатах матчам пройти арбитраж вместе).
- Клэмпинг affected cells при `OverflowAction::Write` теперь учитывается в
  анализе конфликтов согласованно с реальной (клэмпнутой) позицией записи,
  а не с отброшенной абстрактной координатой.
- Правила с 2+ независимыми сдвигами (`ShiftSpec`) теперь применяют `changes`
  один раз на каждую реальную цель сдвига (`shift_targets`), а не один раз на
  их сумму (`total_shift`) — раньше изменения попадали в точку, не
  совпадающую ни с одной реальной целью записи.
- Кэш `active_coords` в `Grid` переведён с `HashSet` + полная пересборка `Vec`
  на `Vec` + индекс `HashMap` со `swap_remove` — удаление теперь O(1)
  амортизированно вместо O(число активных ячеек) (раньше каждый сдвиг головки,
  всегда очищающий исходную позицию, стоил O(A)).

### Changed

- **Бенчмарки** (`benches/`) переписаны: `Criterion`-тесты теперь делают
  setup один раз и замеряют один тик на семпл, а не оборачивают
  самостоятельно-таймингующие циклы внутри `b.iter()`; флаг кастомного
  репортера переименован `--bench` → `--criterion` (Cargo сам всегда
  дописывает `--bench` в argv, что делало кастомный путь недостижимым);
  направление регрессии от baseline исправлено для throughput-метрик
  (раньше рост throughput ложно помечался предупреждением, а падение не
  ловилось); `--output` теперь сохраняет результат даже вместе с
  `--json`/`--quiet`/`--compact`.
- Удалён неиспользуемый вариант `BenchStatus::Fail` из репортера бенчмарков
  (нигде не создавался — не было конструктора `.fail()`, только `.pass()`/`.peak()`).
- Крупные инлайн-блоки `#[cfg(test)] mod tests { ... }` вынесены в соседние
  файлы (`engine/tests.rs`, `conflict_analyzer_tests.rs`, `tm_translator_tests.rs`,
  `rule_store_tests.rs`, `storage_tests.rs`) — чисто структурная правка,
  поведение не меняется.
- `test_config.yaml` перемещён в `configs/`.
- Упрощена сигнатура `run_tick` — больше не принимает явный параметр `active`
  с координатами, вычисляется внутри.
- `detect_matches` распараллелен по активным ячейкам (`rayon`), а не по
  группам правил — масштабируется независимо от числа head-типов.
- Добавлен `[lints.clippy] unwrap_used = "warn"`; убран дублирующийся
  dev-dependency `serde_json` (уже есть в обычных `dependencies`).

### Added

- Property-based тесты (`tests/property_arbitration.rs`,
  `tests/local_arbitration_research.rs`, на `proptest`), доказывающие, что
  локальный раундовый арбитраж даёт результат, идентичный глобальному
  последовательно-жадному эталону (100k+ случаев).
- `README.md` и `specs/specification.md` приведены в соответствие с
  реальной реализацией: формула тай-брейка, `Cell.born_at`, семантика
  репликации при 2+ сдвигах, внутреннее устройство `ChunkStorage`, формат
  YAML-конфига, self-conflict в статическом анализе конфликтов; убрана
  неверная лемма «разные `min_age` устраняют конфликт».
